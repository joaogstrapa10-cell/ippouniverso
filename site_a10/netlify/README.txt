A10 Empreendimentos — Portfólio (deck estático)

COMO PUBLICAR NO NETLIFY (mais rápido, sem login/build):
1. Acesse https://app.netlify.com/drop
2. Arraste esta pasta inteira (ou o arquivo a10-deck.zip) para a área indicada.
3. O Netlify gera uma URL pública na hora (ex.: https://algo-aleatorio.netlify.app).
4. Em "Site settings > Change site name" você pode trocar o subdomínio.

É um site estático de arquivo único (index.html) com fontes e fotos embutidas —
não precisa de build nem de servidor.

Obs.: o botão "Falar com a A10" (cena final) está com um número de WhatsApp
placeholder (5547999999999). Troque pelo número oficial no index.html antes de
apresentar, se quiser o CTA funcionando.
